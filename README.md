# jesusjbriceno.dev

Personal landing page for https://jesusjbriceno.dev — a cracktro-void queue: one bitmap face on an emissive black void, rank is depth, dust drifts behind.

- Static HTML/CSS, no build step, no trackers.
- Multilingual ES/EN (DIP-style switch, persisted locally).
- Served by nginx:1.27-alpine; deployed via Coolify on the family Hostinger VPS.

## Local preview

```bash
docker compose up -d   # serves on :8090
```

## Stack

- Font: Silkscreen (self-hosted, OFL).
